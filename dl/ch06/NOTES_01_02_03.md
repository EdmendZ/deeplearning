## 0. 共同的背景知识

### 0.1 这三段代码到底在干什么？

它们**不是在训练神经网络**，而是在做一个"可视化实验"：

> 给定一个已知形状的"碗状"函数（损失面），让不同的优化器从同一个起点出发，
> 一步一步往碗底（最小值）走，把走过的路径画出来，直观对比不同优化器/学习率策略的差异。

因为函数只有两个变量 `w0`、`w1`，所以路径可以画在二维平面上。

### 0.2 模拟的损失函数

```python
def f(w):
    return (w ** 2).dot(torch.tensor([0.05, 1]))
```

这里 `w` 是一个含两个元素的张量 `[w0, w1]`。展开计算：

```
w ** 2          = [w0², w1²]
.dot([0.05, 1]) = w0² * 0.05 + w1² * 1
```

所以损失函数其实是：

$$f(w_0, w_1) = 0.05 \cdot w_0^2 + 1 \cdot w_1^2$$

**关键点：两个方向的"陡峭程度"差别很大**
- `w0` 方向系数只有 `0.05`，非常平缓（梯度小）
- `w1` 方向系数是 `1`，非常陡峭（梯度大，是 w0 方向的 20 倍）

这种"一个方向平、一个方向陡"的损失面叫做**各向异性 / 病态(ill-conditioned)** 损失面。
它正是用来暴露普通 SGD 缺点、凸显动量法和自适应优化器优势的经典例子。

> `.dot()` 是点积（内积）。这里用点积只是一种"加权求和"的简洁写法，
> 等价于 `0.05*w0**2 + 1*w1**2`。

### 0.3 参数的初始化与梯度追踪

```python
w = torch.tensor([-7.0, 2.0])               # 起点
w_clone = w.clone().detach().requires_grad_(True)
```

- `w` 是起点坐标 `(-7, 2)`，离碗底 `(0, 0)` 很远，便于观察收敛过程。
- `clone()`：复制一份，避免污染原始的 `w`（因为后面要用同一个起点跑多个优化器）。
- `detach()`：从计算图中分离（01 文件用了，02/03 省略了，效果类似）。
- `requires_grad_(True)`：**开启梯度追踪**。只有开启后，`loss.backward()` 才会自动算出
  `w` 的梯度并存到 `w.grad` 里，优化器才能据此更新参数。

### 0.4 等高线绘制（三个文件结尾都有）

```python
w0_grid, w1_grid = np.meshgrid(np.linspace(-7, 7, 100), np.linspace(-2, 2, 100))
y_grid = 0.05 * w0_grid ** 2 + w1_grid ** 2
plt.contour(w0_grid, w1_grid, y_grid, levels=30, colors='gray')
```

- `np.linspace(-7, 7, 100)`：在 [-7, 7] 上均匀取 100 个点（w0 轴）。
- `np.meshgrid(...)`：把两个一维坐标轴"铺开"成二维网格，得到平面上 100×100 个采样点的坐标。
- `y_grid`：在每个网格点上计算损失函数的值。
- `plt.contour(...)`：根据这些高度值画**等高线**。`levels=30` 表示画 30 条等高线。
  等高线越密集的地方，函数越陡峭——你会看到 w1 方向（上下）的线很密，w0 方向（左右）很疏。

## 1. `01_momentum.py` —— 动量法

### 1.1 目标

对比两种优化器的优化轨迹：
1. **普通 SGD**（随机梯度下降）
2. **带动量的 SGD**（Momentum）

### 1.2 核心函数 `grad_desc`

```python
def grad_desc(w, optimizer, iter_num):
    w0_list = []
    w1_list = []

    for i in range(iter_num):
        w0_list.append(w[0].item())   # 记录当前 w0
        w1_list.append(w[1].item())   # 记录当前 w1

        loss = f(w)            # ① 前向：计算损失
        loss.backward()        # ② 反向：求梯度 -> 存入 w.grad
        optimizer.step()       # ③ 更新：根据 w.grad 修改 w
        optimizer.zero_grad()  # ④ 清零：把 w.grad 清零

    return w0_list, w1_list
```

**这就是深度学习训练的标准四步循环**，每一轮迭代：

| 步骤 | 代码 | 作用 |
|------|------|------|
| ① 前向传播 | `loss = f(w)` | 用当前参数算出损失值 |
| ② 反向传播 | `loss.backward()` | 自动求出损失对 `w` 的梯度，存到 `w.grad` |
| ③ 更新参数 | `optimizer.step()` | 沿梯度反方向走一步：`w ← w - lr * w.grad`（SGD 的情形） |
| ④ 梯度清零 | `optimizer.zero_grad()` | PyTorch 梯度默认**累加**，不清零会越加越大 |

> **为什么要 `.item()`**：把单元素张量转成普通 Python 数字再存进列表，
> 切断与计算图的联系，避免内存泄漏，也方便后续画图。

每次循环开头都把当前的 `w0`、`w1` 存进列表，循环结束后这两个列表就记录了**完整的优化轨迹**。

### 1.3 主流程

```python
if __name__ == '__main__':
    w = torch.tensor([-7.0, 2.0])   # 1. 起点
    iter_num = 500                  # 2. 迭代 500 次
    lr = 0.9                        #    学习率 0.9（较大）

    # 3.1 普通 SGD
    w_clone = w.clone().detach().requires_grad_(True)
    optimizer = optim.SGD([w_clone], lr)
    w0_list, w1_list = grad_desc(w_clone, optimizer, iter_num)
    plt.plot(w0_list, w1_list, color='red', label='SGD')

    # 3.2 动量法
    w_clone = w.clone().detach().requires_grad_(True)
    optimizer = optim.SGD([w_clone], lr, momentum=0.1)   # 多了 momentum 参数
    w0_list, w1_list = grad_desc(w_clone, optimizer, iter_num)
    plt.plot(w0_list, w1_list, color='blue', label='Momentum')
```

**两次实验唯一的区别**就是 `optim.SGD` 多了一个 `momentum=0.1` 参数。

> 注意：第二次实验前重新 `clone()` 了一份新参数，保证两个优化器**从同一起点出发**，对比才公平。

### 1.4 SGD vs 动量法 —— 原理对比

**普通 SGD 的更新公式：**

$$w \leftarrow w - lr \cdot g$$

（`g` 是当前梯度）。在 w1 这种陡峭方向上，梯度大、步子迈得大，
容易"冲过头"再被拉回来，于是在峡谷两壁间**来回震荡**，收敛很慢。

**动量法的更新公式：**

$$v \leftarrow \beta \cdot v + g \qquad w \leftarrow w - lr \cdot v$$

它维护一个"速度" `v`，是历史梯度的累积（`β` 即 `momentum`）。

- 在 w0 这种方向一致的平缓方向上：梯度方向始终相同，速度不断累积 → **加速前进**。
- 在 w1 这种来回摆动的方向上：正负梯度相互抵消 → **抑制震荡**。

**画图结果：** 红线（SGD）在陡峭方向反复横跳、路径曲折；
蓝线（Momentum）更平滑、更快冲向碗底。

### 1.5 结尾的 meshgrid 小演示

```python
a, b = np.meshgrid([1,2], [3,4,5,6])
print(a)
print(b)
```

这段和优化无关，只是单独演示 `meshgrid` 的行为，帮助理解前面画等高线时它做了什么：

```
a = [[1 2]      b = [[3 3]
     [1 2]           [4 4]
     [1 2]           [5 5]
     [1 2]]          [6 6]]
```

`meshgrid` 把 x 轴的 2 个值和 y 轴的 4 个值组合成 4×2 的网格，
`a` 是每个网格点的 x 坐标，`b` 是每个网格点的 y 坐标——两者配对就得到全部 8 个网格点。

## 2. `02_lr_step.py` —— 等间隔学习率衰减（StepLR）

### 2.1 目标

演示**学习率调度器（lr_scheduler）**：训练过程中动态调整学习率。
StepLR 的策略是——**每隔固定步数，把学习率乘以一个衰减系数**。

### 2.2 相比 01 的变化

`desc` 函数比 01 的 `grad_desc` 多做了两件事：

```python
def desc(w, optimizer, lr_scheduler, iter_num):   # 多了 lr_scheduler 参数
    w0_list, w1_list, lr_list = [], [], []         # 多了 lr_list 记录学习率

    for i in range(iter_num):
        w0_list.append(w[0].item())
        w1_list.append(w[1].item())
        lr_list.append(optimizer.param_groups[0]["lr"])  # ★新增：记录当前学习率

        loss = f(w)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
        lr_scheduler.step()    # ★新增：更新学习率

    return w0_list, w1_list, lr_list
```

两处关键新增：

1. **读取当前学习率**
   ```python
   optimizer.param_groups[0]["lr"]
   ```
   优化器内部把参数分成若干"参数组(param_groups)"，每组有自己的超参数。
   这里读取第 0 组的 `lr`，就能拿到**当前这一步实际使用的学习率**，存进 `lr_list` 供画图。

2. **调度器步进**
   ```python
   lr_scheduler.step()
   ```
   **注意调用顺序**：必须放在 `optimizer.step()` **之后**。
   调度器每被调用一次就检查"是否到了该衰减学习率的时刻"，到了就修改优化器里的 `lr`。

> ⚠️ 常见误区：`optimizer.step()`（更新参数）和 `lr_scheduler.step()`（更新学习率）
> 是两件不同的事，前者每步都改参数，后者按策略改学习率。

### 2.3 调度器的创建

```python
sgd_optimizer = optim.SGD([w_clone], lr=lr)              # lr=0.9
lr_scheduler = StepLR(sgd_optimizer, step_size=20, gamma=0.7)
```

`StepLR` 接管了 `sgd_optimizer` 的学习率：

- `step_size=20`：每 **20 步**衰减一次。
- `gamma=0.7`：每次衰减就 **乘以 0.7**。

所以学习率的变化是**阶梯状**的：

| 步数区间 | 学习率 |
|----------|--------|
| 0 ~ 19   | 0.9 |
| 20 ~ 39  | 0.9 × 0.7 = 0.63 |
| 40 ~ 59  | 0.63 × 0.7 ≈ 0.441 |
| 60 ~ 79  | ≈ 0.309 |
| …        | 每 20 步再 × 0.7 |

### 2.4 双子图绘制

```python
fig, ax = plt.subplots(1, 2, figsize=(10, 5))   # 1 行 2 列两张子图
ax[0].plot(w0_list, w1_list, label="SGD")        # 左图：参数优化轨迹
ax[1].plot(lr_list)                              # 右图：学习率变化曲线
...
ax[0].contour(w0_grid, w1_grid, y_grid, ...)     # 左图叠加等高线
```

- **左图**：参数 `(w0, w1)` 的优化轨迹 + 损失面等高线。
- **右图**：学习率随迭代步数的变化，会看到一条**阶梯状下降**的折线。

### 2.5 为什么要做学习率衰减？

- 训练**初期**：用大学习率，快速逼近最优解附近。
- 训练**后期**：用小学习率，在最优解附近精细微调，避免步子太大反复横跳、错过最低点。

## 3. `03_lr_multi.py` —— 里程碑式学习率衰减（MultiStepLR）

### 3.1 目标

和 02 几乎完全一样，**唯一的区别在于换了一种调度器**：`MultiStepLR`。

### 3.2 与 02 的唯一差异

```python
# 02 用的是 StepLR（等间隔）
lr_scheduler = StepLR(sgd_optimizer, step_size=20, gamma=0.7)

# 03 用的是 MultiStepLR（指定里程碑）
lr_scheduler = MultiStepLR(sgd_optimizer, [20, 50, 100], gamma=0.7)
```

`desc` 函数、主流程、绘图代码……全部和 02 相同。

### 3.3 StepLR vs MultiStepLR 的区别

| | StepLR | MultiStepLR |
|---|--------|-------------|
| 衰减时机 | **等间隔**：每 `step_size` 步衰减一次 | **指定里程碑**：只在 `milestones` 列出的步数衰减 |
| 02/03 参数 | `step_size=20` | `milestones=[20, 50, 100]` |
| 衰减时刻 | 20, 40, 60, 80, 100, 120 … | 只在 20、50、100 这三步 |

**MultiStepLR 的学习率变化（gamma=0.7）：**

| 步数区间 | 学习率 |
|----------|--------|
| 0 ~ 19    | 0.9 |
| 20 ~ 49   | 0.9 × 0.7 = 0.63 |
| 50 ~ 99   | 0.63 × 0.7 ≈ 0.441 |
| 100 ~ 499 | 0.441 × 0.7 ≈ 0.309（之后不再变化） |

可见 MultiStepLR **更灵活**：你可以自己决定在哪些关键节点降学习率，
而不是机械地等间隔降。常用于"前期密集衰减、后期稳定"的训练安排。

## 4. 三个文件横向对比总结

| | 01 momentum | 02 lr_step | 03 lr_multi |
|---|---|---|---|
| **核心主题** | 优化器：动量法 | 学习率调度：等间隔 | 学习率调度：里程碑 |
| 损失函数 `f(w)` | 相同 | 相同 | 相同 |
| 训练循环 | `grad_desc`（4 步） | `desc`（6 步，多了 lr 记录与调度） | 同 02 |

| 迭代次数 | 500 | 500 | 500 |
| 对比对象 | SGD vs Momentum | 单条 SGD 轨迹 + 学习率曲线 | 单条 SGD 轨迹 + 学习率曲线 |
| 关键 API | `optim.SGD(momentum=)` | `StepLR(step_size, gamma)` | `MultiStepLR(milestones, gamma)` |
| 绘图 | 单图（两条轨迹） | 双子图（轨迹 + 学习率） | 双子图（轨迹 + 学习率） |

### 学习脉络

```
01：怎么让优化器走得更快更稳？  → 改进"更新方向"（动量）
02：训练中怎么调整学习率？      → 改进"步长大小"（等间隔衰减）
03：能不能更灵活地调学习率？    → 自定义衰减时机（里程碑衰减）
```

> 动量（改方向）和学习率调度（改步长）是**两个正交的维度**，
> 实际训练中常常同时使用：用 Adam/带动量的 SGD + 学习率调度器。

## 5. 关键概念速查

| 概念 | 一句话解释 |
|------|-----------|
| `requires_grad_(True)` | 开启梯度追踪，参数才能被自动求导和更新 |
| `loss.backward()` | 反向传播，自动计算梯度并存入 `.grad` |
| `optimizer.step()` | 根据梯度更新参数 |
| `optimizer.zero_grad()` | 清空梯度（PyTorch 梯度默认累加） |
| `lr_scheduler.step()` | 按策略调整学习率，放在 `optimizer.step()` 之后 |
| `optimizer.param_groups[0]["lr"]` | 读取当前实际学习率 |
| `momentum` | 动量系数，累积历史梯度以加速、抗震荡 |
| `StepLR` | 每隔固定步数衰减学习率 |
| `MultiStepLR` | 在指定的若干步数处衰减学习率 |
| `gamma` | 学习率衰减系数（每次乘以它） |
| `np.meshgrid` | 由坐标轴生成二维网格点，用于画等高线 |
| `plt.contour` | 画等高线，可视化损失面形状 |
| `.item()` | 单元素张量 → Python 数字 |
